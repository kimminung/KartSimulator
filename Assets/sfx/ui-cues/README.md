# 기록·랩·오류 효과음

사용자가 2026-10-14 추가 후보 전체를 승인했다. 지정 RetireX Online 개발 RP의 `sounds/rxoeffect/`에서 원본 3개를 보존하고 AAC M4A로 변환했다. 원본 음량·재생 속도·페이드·채널 수를 유지하며 정규화·트리밍하지 않았다.

| 파일 | 용도 | 길이 |
| --- | --- | --- |
| `cue_record.m4a` | 신기록 | 약 3.427초 |
| `cue_middle_lap.m4a` | 일반 랩 통과 | 약 1.340초 |
| `cue_error.m4a` | 오류 | 약 1.723초 |

총 랩 완료에는 일반 랩 효과음을 중복 재생하지 않는다. 신기록·랩 배너와 음원 이벤트 연결 및 실제 앱 청취는 테크 후속 작업이다. 원본 출처 기록은 `Assets/sfx/LICENSES.md`에 있으며 기존 엔진음의 CC0 기록을 이 파일에 적용하지 않는다.

`build.ps1`은 이 PC의 FFmpeg로 다시 변환하고 AAC 디코드·메타데이터·해시를 `validation.json`에 기록한다. 지정 원본 RP는 읽기만 한다.
