산출물은 design 브랜치 커밋으로 전달한다. 커밋 내역은 Git 기록, 검증 결과는 이 폴더의 validation.json을 확인한다. 앱 통합·USDZ·실기기 실행은 이 디자인 납품의 후속이다.
