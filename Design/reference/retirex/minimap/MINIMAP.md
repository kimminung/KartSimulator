# RetireX Online 미니맵 — 동작 전부와 핀치 카트로 옮기기

RetireX의 경기 미니맵은 HUD 오른쪽 위의 작은 정사각 지도에 **자기 화살표 1개**와 **다른 레이서 점 최대 7개**를 그린다. 아래는 실제 운영 코드와 리소스팩이 하는 일을 그대로 정리한 것이다. 코드는 옮기지 말고(마인크래프트 전용 구조다) 규칙만 가져간다.

## 1. 지도 범위(bounds) — 트랙 데이터에서 계산

```text
모든 게이트의 중심점과 양쪽 기둥(left, right) 좌표를 모은다.
minX, maxX, minZ, maxZ 를 구한다.
span = max(maxX - minX, maxZ - minZ) × 1.14      # 긴 변 기준, 여백 14 %
x0 = (minX + maxX - span) / 2                    # 가운데 정렬
z0 = (minZ + maxZ - span) / 2
```

- 지도는 항상 **정사각형**이다. 짧은 변 쪽에 여백이 더 생긴다.
- 지도 위가 북쪽(-z), 오른쪽이 동쪽(+x)이다. 높이(y)는 쓰지 않는다.
- 각 `tracks/<id>/track.json`의 `minimap.bounds`가 이 식으로 구한 값이다.
- 트랙을 고치면(게이트를 옮기면) 범위와 그림을 함께 다시 만든다. 따로 놀면 점이 길에서 벗어난다.

## 2. 지도 그림 — 512 × 512 PNG

| 항목 | 규칙 |
| --- | --- |
| 크기 | 512 × 512, 정사각, RGBA |
| 좌표 | 픽셀 (u, v) ↔ 월드 `x = x0 + u/512 × span`, `z = z0 + v/512 × span` |
| 바탕 | 투명(한 가지 색이면 됨 — HUD 합성이 (0,0) 픽셀을 바탕색 견본으로 씀) |
| 길 | **한 가지 색**: 어두운 테두리(`#142737`) 위에 밝은 노면(`#f4f7ec`). 높이별 색 구분 없음 |
| 굵기 | 경기장 크기에 비례: 966 m 범위 기준 테두리 40 px, 노면 31 px(지름길은 12 / 8 px) |
| 지름길 | 본선보다 가는 선 |
| 점프 | 공중 구간은 그리지 않는다(끊긴 선) — 실제로 달리는 땅만 그림 |
| 결승선 | 짧은 파란 선 + 진행 방향 작은 삼각형(`#22b4dd`) |

운영자 요청으로 "한 가지 색, 높이 색 없음, 점프 연결선 없음"이 규칙이 됐다. 지도가 복잡하면 달리면서 읽히지 않는다.

## 3. HUD 그림 — 프레임 합성

`minimap_hud.png` = 지도 그림을 픽셀 프레임(`frame_pixel.png`, 128 → 512 최근접 확대) 안에 넣은 것.

- 트랙 그림이 든 사각형 안에서 **바탕색과 다른 픽셀만** 지도 그대로 쓰고, 나머지는 프레임을 알파 78 %로 둔다.
- 게임에서는 여기에 알파 0.4를 한 번 더 곱해 반투명하게 띄운다(주행 시야를 가리지 않게).

## 4. 플레이어 표시 — 자기 화살표와 다른 레이서 점

| 표시 | 그림 | 크기 | 색 |
| --- | --- | --- | --- |
| 자기 카트 | 화살표 `self_N.png` | 24 × 24 | 자기 카트 색 |
| 다른 레이서(최대 7) | 점 `marker_N.png` | 16 × 16 | 그 레이서 카트 색 |

색 번호 `N`(0~16)과 실제 색은 `markers_sheet.png`에 있다.

| N | 색 | N | 색 | N | 색 |
| --- | --- | --- | --- | --- | --- |
| 0 | 검정 #252934 | 6 | 청록 #27a5a8 | 12 | 하늘 #55b9e7 |
| 1 | 빨강 #ee4949 | 7 | 밝은 회색 #a5adb2 | 13 | 자홍 #c853d5 |
| 2 | 초록 #478143 | 8 | 회색 #484d58 | 14 | 주황 #f28c28 |
| 3 | 갈색 #825637 | 9 | 분홍 #ef88ad | 15 | 흰색 #f1f2ee |
| 4 | 파랑 #345cdc | 10 | 연두 #7bb82a | 16 | 무도색(은색) #d5dce5 |
| 5 | 보라 #884bc3 | 11 | 노랑 #f7d439 | | |

- 개인전은 각자 카트 도색 색, 팀전은 빨강팀 1·파랑팀 4로 칠한다.
- 화살표는 진행 방향(`yaw`, 0~359°)으로 돈다. 점은 방향이 없다.
- **칸 순서는 출발 그리드 순서**다(순위 아님). 나간 사람·완주한 사람은 숨긴다.
- AI 레이서도 점으로만 나온다.

### 위치를 보내는 방법(서버 → 화면)

```text
fx = clamp((x - x0) / span, 0, 1)
fz = clamp((z - z0) / span, 0, 1)
packed = 1 + round(fx × 1023) + 1024 × round(fz × 1023)      # 0 = 없음
```

- 화면 쪽은 `tx = ((packed-1) mod 1024) / 1023`, `tz = floor((packed-1) / 1024) / 1023`로 되돌린다. 1023단계라 범위 463 m 트랙에서 오차는 최대 반 칸(약 0.23 m)이다.
- 그림 위 위치: `((tx - 0.5) × 지도너비, (0.5 - tz) × 지도너비)` (가운데 기준).
- **보간**: 새 값이 오면 바로 옮기지 않고 프레임마다 `lerp(이전, 새 값, delta × 12)`로 따라간다. 0.3(지도 폭의 30 %) 넘게 튀면(순간이동·복귀) 바로 옮긴다.
- **주기**: 4틱(0.2초)마다, 바뀐 값만 보낸다(그래픽 하옵션 10틱). 새로 보는 사람에게는 방향을 8틱 간격으로 두 번 더 보낸다.

### 언제 보이나

- 경기 인트로가 끝나 카운트다운 직전 HUD가 켜질 때부터, 주행·완주 대기 중까지.
- 로딩·쇼케이스·완주 뒤·중단·퇴장에는 끈다. 속도 다이얼과 함께 켜지고 꺼진다.
- 다른 차원(다른 경기장)에 있는 사람은 지도를 끈다.

## 5. 핀치 카트로 옮기기 (제안)

핀치 카트는 1인 타임어택이라 "다른 레이서 점"이 필요 없다. 다만 같은 규칙이 그대로 쓸모 있다.

| RetireX | 핀치 카트 |
| --- | --- |
| 게이트 중심·기둥으로 bounds | 타일 격자 전체 + 10 % 여백(테크 PRD 9장) — 같은 생각, 기준만 타일 |
| 정사각 512 그림, 위 = 북 | `track_XX_minimap.png` 512, 위 = 북(-Z)로 맞추면 RetireX 그림과 바로 비교 가능 |
| 한 가지 색 노면, 높이 색 없음 | `Design/style-guide.md` 1-4: 노면 `mm-road`, 테두리 `mm-edge`, 바탕 `ui-panel` 78 % — RetireX 미니맵 색을 그대로 쓴다 |
| 자기 화살표(진행 방향 회전) | 테이블 위 0.25배 카트 마커 + 헤딩 회전 = 같은 역할 |
| 보간 `lerp(delta×12)` + 0.3 넘으면 즉시 이동 | `MinimapSyncSystem`이 매 프레임 갱신하므로 보간은 필요 없고, **리스폰 때 즉시 이동** 규칙만 가져간다 |
| 고스트(다른 레이서 점) | 최고 기록 고스트를 넣는다면 `marker` 방식(색 점, 방향 없음)이 잘 읽힌다 |
| 체크포인트 | RetireX 지도에는 KEY를 그리지 않는다(지도 단순화). 핀치 카트는 라벨 3개를 둔다(디자인 PRD 6장) |

- 이 폴더의 `markers/`, `frame_pixel.png`은 RetireX 운영자 쪽 그림이다. 핀치 카트에 그대로 써도 된다(결정 20-12). 팔레트도 RetireX 색 체계를 쓰므로 다시 칠할 필요가 없다(결정 20-11). 넣을 때 PRD 이름 규칙으로 파일명만 바꾼다(결정 20-13).
- 미니맵 목업과 깃발·라벨 아이콘은 `Design/mockups/minimap.png`, `Design/icons/icon_minimap_*.svg`로 따로 만들었다.
