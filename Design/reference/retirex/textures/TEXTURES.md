# 텍스처 — RetireX가 무엇을 썼고, 핀치 카트는 무엇을 쓰나

> **결정 21(2026-10-10):** 마인크래프트(Mojang) 텍스처·소리는 이 앱에 **임시로도** 쓰지 않는다. 핀치 카트는 처음부터 직접 그린 대체 텍스처(`Design/textures/`)를 쓰고, 정식 텍스처가 나오면 같은 파일명으로 덮어쓴다.

## 1. RetireX 쪽 출처와 핀치 카트에서의 취급

| 출처 | 내용 | 핀치 카트에서 |
| --- | --- | --- |
| **Mojang 공식 샘플 팩** "Example vanilla resource pack"(github.com/Mojang/bedrock-samples의 `resource_pack/`, 엔진 1.26.50) | 돌·흙·잔디·물·양털·콘크리트·유리 같은 마인크래프트 기본 블록 텍스처 | **쓰지 않는다.** RetireX 렌더가 이걸로 그려져 있으니 "어떤 재료가 어떤 색감으로 쓰였나"만 본다. 파일은 받지도, 복사하지도 않는다 |
| **RetireX 자체 그림**(`retirex_track_blocks/`) | 트랙 배너, 부스트 발판, 점프 발판, 가드레일 화살표 | 써도 된다(결정 20-12, 디자이너 본인 프로젝트). 넣을 때 PRD 이름 규칙으로 파일명을 바꾼다(결정 20-13) |

RetireX의 편집기 렌더(`render_*.png`)는 두 출처를 섞어 그렸다. 렌더러는 샘플 팩의 `blocks.json`에서 블록 이름을 텍스처 키로 바꾸고, 다시 `textures/terrain_texture.json`에서 파일 경로를 찾는다.

## 2. RetireX 도로 단면 (모든 아스팔트 트랙 공통)

가장자리에서 안쪽으로 잰 거리 `e`(블록) 순서다. 폭 30칸 도로(반폭 15)면 양쪽이 대칭이고, 안쪽 28칸이 주행 폭이다. 오른쪽 열은 핀치 카트 스타일 가이드 1-1장의 색 이름이다.

| e(블록) | 역할 | 블록 | 핀치 카트 색 |
| --- | --- | --- | --- |
| -3 바깥 | 보도 | 회색 양털 | `grass`(타일 여백) |
| -2 ~ -1 | 보도 테두리 | 응회암 / 다듬은 응회암(2칸 교대) | — |
| -1 ~ 0 | 연석 경사 | 응회암 계단(도로 쪽으로 기울어짐) | `curb` |
| 0 ~ 1 | 벽 | 검은 양털 바닥 + 위에 **노란 유리판** | `rail` + `edge-line` 기둥 |
| 1 ~ 2 | 가장자리 선 | 노란 콘크리트 / 노란 양털(2칸 교대) | `edge-line` |
| 2 ~ 3 | 노면 경사 띠 | 흑암 계단 | `road-alt` |
| 3 ~ 중앙 | 노면 | 검은 양털 / 검은 콘크리트 2칸 줄무늬 | `road` / `road-alt` 8유닛 교대 |
| 7 ~ 9 (폭 22 이상) | 차선 | 흰 양털 2칸 + 검정 2칸 점선 | `lane-line` |
| 중앙 2칸 (폭 18 이상) | 중앙선 | 노란 콘크리트/양털 + 양옆 흑암 계단 | 핀치 카트 노면 3 m에서는 생략 |
| 벽 위 | 가드레일 | 주황 화살표 판(8칸마다 한 쌍), 배너 3조각(20칸마다) | `edge-line` 기둥(8유닛마다) |
| 노면 위 | 가속 띠 / 점프 띠 | 폭 전체를 가로지르는 발판 | 1차 범위 밖(효과로 대신할 수 있음) |

- 노면을 두 재료로 2칸씩 줄무늬 지게 깐 것은 넓은 검은 면이 밋밋해 속도감이 안 나서다. 핀치 카트 타일도 1~2 px 미세 줄무늬 대신 **면 2톤 교대**로 같은 효과를 냈다(`tiles.png`, 디자인 PRD "1픽셀 디테일 금지"와도 맞음).
- 오르막·내리막은 반 블록(0.5 m) 계단으로만 만든다. 1블록 턱에는 카트가 걸린다.

## 3. 대체 텍스처 (`Design/textures/tex_<이름>.png`, 16 × 16)

`node Design/tools/textures.mjs`로 만든다. 남의 파일을 읽지 않고, 씨앗값 고정 잡음과 단순한 무늬를 스타일 가이드 색으로 칠한다. 미리보기는 `Design/textures/_sheet.png`다(2 × 2로 이어 붙여 이음새를 보여 준다).

| 대체 텍스처 | 대신하는 RetireX 재료(예) | 트랙 5종 평균 비중* |
| --- | --- | --- |
| `tex_stone` | 돌, 안산암, 응회암, 자갈 | 25.3 % |
| `tex_dirt` | 흙, 진흙, 흙길 | 15.7 % |
| `tex_grass_top` / `tex_grass_side` | 잔디 블록(윗면/옆면) | 10.8 % |
| `tex_plaster_white` | 석영, 퍼퍼(RetireX에서 석영처럼 보임), 버섯 자루(흰 벽) | 9.7 % |
| `tex_stone_bricks` | 석재 벽돌 | 9.2 % |
| `tex_water` | 물 | 7.8 % |
| `tex_glass` | 유리, 색유리, 유리판 | 3.8 % |
| (평면 색) | 양털·콘크리트(노면·선·건물 색면) — 스타일 가이드 1-1의 색 | 3.7 % |
| `tex_metal` | 철 블록, 철 다락문, 사슬, 랜턴 | 3.2 % |
| `tex_roof_tile` | 테라코타, 갈색 버섯 블록(지붕) | 2.9 % |
| `tex_leaves` | 나뭇잎 | 2.6 % |
| `tex_sandstone` | 사암, 모래 | 2.0 % |
| `tex_planks` | 판자, 나무 계단·반 블록·울타리 | 1.6 % |
| `tex_brick` | 벽돌 | 0.4 % |
| `tex_log_side` | 통나무 | 0.3 % |

\* 고가(`nad_goga`)를 뺀 4종에서, 블록 수 기준이다. 대응이 없는 것(꽃, 풀, 뼈 블록 등)은 1 % 남짓이다. 블록별 대응은 `texture-usage.json`의 `standIn`에 있다(`flat` = 평면 색, `retirex-art` = RetireX 자체 그림, `null` = 아직 없음).

- 돌·흙은 대부분 땅속이라 보이지 않는다. 눈에 보이는 면은 잔디·노면·물·건물 외벽이다. 정식 텍스처를 그릴 때는 이 순서로 우선순위를 둔다.
- 건물 외벽은 흰색·크림·회색 바탕에 주황 기와, 분홍 상점, 파란 지붕이 포인트다(스폰 도시 색감).

- RetireX 리소스팩은 퍼퍼·레드 네더 벽돌·사암 등 13장을 자체 그림으로 덮어쓴다. 그래서 렌더에서 퍼퍼가 석영처럼 보인다.

## 5. 정식 텍스처로 바꾸는 순서

1. **트랙 타일 4종**(`Assets/blockbench/tiles/tiles.png`)은 처음부터 스타일 가이드 색으로 칠했다. 교체 대상이 아니다.
2. 풍경을 만들 때는 `tex_*` 대체 텍스처를 쓴다. 마인크래프트 파일은 쓰지 않는다.
3. 정식 텍스처는 **같은 파일명·같은 크기(16 × 16)**로 `Design/textures/`에 덮어쓴다. 그러면 코드와 모델을 바꿀 필요가 없다.
4. 크기를 바꾸려면(예: 32 × 32) 모든 `tex_*`를 함께 바꾸고 테크에 알린다. UV는 텍스처 크기와 무관하게 0~1이지만, 픽셀 밀도가 섞이면 보기 싫다.
