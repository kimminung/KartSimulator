# 맵 렌더링·미리보기 — RetireX가 쓴 도구와 흐름

RetireX 트랙은 마인크래프트 월드로 만들어지지만, 만드는 동안에는 **게임을 켜지 않고** 설계 데이터에서 바로 렌더해 확인한다. 핀치 카트에서도 같은 생각(데이터 → 바로 그림)이 유용하다.

## 1. 쓰는 프로그램

| 단계 | 프로그램 | 하는 일 | 결과물 예 |
| --- | --- | --- | --- |
| 설계 | Node.js 스크립트(자체) | 트랙 중심선(직선·원호 조각을 거북이처럼 이어 그림) → 노면 칸 → 블록 배치, 풍경 배치 | 설계 블록 목록, 코스 데이터 |
| 검사 | Node.js 스크립트(자체) | 물 샘, 배너 방향, 노면 위 장애물, 점프 통로, 출발 칸 받침, 건물 정면 방향 | 검사 보고 |
| 3D 렌더 | **BedrockMap**(자체 빌드한 OpenGL 렌더러, `BedrockMap.exe`) + `block-mesh.cjs` | 블록 목록 → 텍스처 입힌 메시 → 직교 투영 PNG. 각도(yaw·pitch)와 잘라낼 범위를 지정 | `render_*.png` |
| 평면 확인 | Node.js(`topview.cjs`, 자체 PNG 작성기) | 기둥마다 가장 위 블록 색으로 한 칸 = 2픽셀 평면도 | 평면 스케치 |
| 2D 합성 | Node.js + **sharp**(이미지 라이브러리) | SVG → PNG, 미니맵·카드·도면·HUD 합성 | `minimap.png`, `card.png`, `course_plan.png` |
| 모델 | **Blockbench** 형식 JSON을 Node로 생성(풍차·카트), 렌더는 자체 소프트웨어 렌더러 | 모델 검토 이미지 5방향 | `windmill_model.png` |
| 실제 확인 | 마인크래프트 베드락 클라이언트(Windows) | 탐방용 월드를 깔고 직접 걸어 보기 | 운영자 스크린샷 |
| 주행 검증 | Go 서버 코드의 시험 장치(헤드리스) | 봇 8대 경기, 점프 착지, 지름길 판정을 실제 물리로 | 검증 보고 |

- RetireX 렌더의 텍스처는 Mojang 샘플 팩(기본 블록)과 RetireX 리소스팩(자체 그림)에서 온다. 핀치 카트는 Mojang 것을 쓰지 않는다(결정 21). 대신 `Design/textures/`의 대체 텍스처를 쓴다(`textures/TEXTURES.md`).
- 렌더는 편집기 근사다. 조명·투명도는 게임과 다르다. **렌더에서 괜찮아도 게임에서 문제가 날 수 있다**(이번 트랙 2판이 그랬다 — `KNOWHOW.md` 7장).

## 2. 렌더 흐름

```text
설계 데이터(블록 목록)
  → 잘라낼 범위 [min, max) 와 시점(yaw, pitch) 선택
  → 블록마다 텍스처 키 → 텍스처 파일 → 면(quad) 생성, 가려진 면 제거
  → 직교 카메라로 렌더 → PNG
```

- 시점 약속: yaw 0 = 북쪽 면을 봄, 90 = 동쪽, 180 = 남쪽, 270 = 서쪽. pitch 12~15°는 도로에서 본 높이, 35~50°는 전체 조망.
- 큰 범위(46만 m² 이상)도 30초 안쪽. 줄마다(도로 한 구간마다) 렌더해 "도로에서 건물 정면이 보이는지"를 확인한다.

## 3. 핀치 카트에서 비슷하게 보기

| RetireX 방식 | 핀치 카트 대응 |
| --- | --- |
| 설계 데이터에서 바로 렌더 | 트랙 JSON → 타일을 격자에 놓는 미리보기. `node Design/tools/tiles.mjs`가 `Tracks/track_01.json`으로 `Design/reference/tiles_preview_track01.png`를 그린다(의존성 없는 자체 렌더러). Mac에서는 `.glb`를 Reality Composer Pro로 확인 |
| 직교 45° 조망 | 디자인 PRD의 "위에서 45°" 테이블탑 시점과 같은 각도라 비교가 쉽다 |
| 도로 높이(pitch 12°) 렌더 | 1.5 m 카트 눈높이 시점 스크린샷 — 코너가 너무 급한지, 벽이 시야를 가리는지 확인 |
| 평면 스케치(`topview`) | `Tracks/tools/`의 미니맵 이미지 생성과 같은 역할 |

- 이번에 만든 타일 미리보기 `Design/reference/tiles_preview.png`는 Node로 그린 등각 투영 그림이다(`Design/tools/tiles.mjs`).
