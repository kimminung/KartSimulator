"뉴암스테르담"은 이 서버의 스폰 도시 이름이다(실제 암스테르담이 아님). 그 도시의 건물을 떼어 와 트랙 주변을 꾸민다.

## 2. 트랙별 특징

### 뉴암스테르담 캐널 (`nad_woonha`) — 입문
- 운하 공원 둘레를 도는 사각형에 가까운 루프. 폭 28 m가 끝까지 같고 높이 차가 없다.
- 넓은 90° 코너 위주라 처음 타는 사람도 벽에 덜 부딪힌다. 가속 띠는 직선 끝 3곳.
- 주변: 운하(물), 공원, 도시 블록. 안쪽 벽을 걷어 시야가 트였다.
- 핀치 카트 첫 트랙(쉬움, 커브 4)의 모양 참고에 가장 가깝다.

### 뒷산 덩굴 동굴 (`dyc_turnel`) — 자연 코스
- 흙길·나무 다리·개울·버섯 숲·동굴을 지나는 자연 코스. 폭이 12~32 m로 크게 변한다(동굴과 다리는 좁다).
- 길 가장자리는 울타리나 자연 암벽으로 막았다. 동굴 안 종유석은 주행 통로를 피해 달았다.
- 좁아지는 구간 앞에서 속도를 줄이는 리듬이 핵심이다.

### 뉴암스테르담 탁 트인 고가 (`nad_goga`) — 입체 교차
- 8자형으로 자기 길을 고가로 넘는다(높이 -37 ~ -23, 14 m).
- 경사로 오르내림이 길고, 고가 끝의 **점프 지름길**(2026-10-07 추가)을 타면 아래 길로 뛰어내려 앞서 나간다. 지름길 게이트 8개(분기 62번 → 합류 85번).
- 체크포인트(KEY)가 2개뿐이라 지름길 판정을 게이트 순서로 한다.

### 뉴암스테르담 발가락 (`nad_toe`) — 장거리
- 발 모양 코스: 출발 직선 → 엄지발가락 → 나머지 발가락(연속 U턴) → 오목한 안쪽 → 뒤꿈치 → 골인. 3.4 km로 가장 길어 2랩이다.
- 경사(높이 6 m)와 **넓은 가속 띠**(블록 2,841개, 26구간이 폭 전체를 가로지름)가 많다.
- 가드레일 방향판 1,579개가 진행 방향을 알려 준다(2026-10-07 주행 방향을 반대로 바꾸며 모두 반전).

### 뉴암스테르담 풍차 제방 (`nad_pungcha`) — 난이도 4 (2026-10-10 신규)
- 순서: 출발 광장 → 시청 코너 → 운하 직선·S자 → 도개교(오르막·내리막) → 시계탑 직각 → **구시가 Z 골목(폭 10 m)** → 시장 직선 → **수문 갈림길** → 풍차 헤어핀(폭 12 m) → 간척지 시케인·헤어핀 → 제방(오르막 4 m, 직선 101 m) → 끊어진 다리 **점프(틈 20 m)** → 마을 문 Z → 골인.
- 지름길: 본선이 수문 쪽으로 돌아갈 때 곧장 가는 8 m 폭 골목(71.5 m, 우회로 142 m). 한 바퀴 2.4~5초 이득.
- 풍차 7기는 블록이 아니라 날개가 도는 모델(`track.json`의 `props`).
- 기술 요구: 좁은 Z 골목에서 짧은 드리프트, 헤어핀 풀 드리프트, 점프 착지 정렬. 자세한 설계는 `../KNOWHOW.md` 6장.

## 3. `track.json` 형식

```text
schema        "retirex-track-reference/1"
id, name, laps, difficulty, modes
units         좌표 규약: 1 = 1 m(블록 1칸), +x 동, +z 남(지도 위가 북), y 위
lapLength     본선 게이트 중심을 이은 한 바퀴 길이(m)
gateCount     main(본선) / shortcut(지름길) / checkpoints(KEY)
halfWidth     본선 게이트의 주행 반폭 최솟값·최댓값(벽 안쪽)
heightRange   게이트 바닥 높이 범위
branches      지름길: splitIndex 본선 게이트 뒤에서 갈라져 지름길 게이트(본선 뒤에 순서대로 붙음)를 지나 joinIndex로 합류
start         finishGate(0번 = 결승선), grid 8칸 {x,y,z,yaw}(yaw 0 = +z, 90 = -x), gridSnap
minimap       bounds {x,z,span}, 그림 좌표 변환식
itemBoxes     아이템전 상자 위치 [x,y,z] (없으면 빈 배열)
props         모델 장식(풍차 등) {type,x,y,z,yaw,scale,variant}
boostPads     가속 띠 칸 [x,y,z] (설계 데이터가 있는 트랙만, 구간 모서리만 있을 수 있음)
gates[]       { i, x, z, y, halfWidth, kind: finish|checkpoint|flow, route: main|shortcut, left:[x,z], right:[x,z] }
```

- 게이트는 약 5.5 m 간격으로 길을 가로지르는 선분이다. `left`/`right`는 그 선분 양 끝(벽 안쪽 기둥 위치)이다. 게이트를 차례로 이으면 노면 모양이 나온다(`course_plan.png`이 그렇게 그린 것).
- `kind: checkpoint`(KEY)는 반드시 지나야 랩으로 친다. 서버의 랩 조건은 "KEY 전부 + 일반 게이트 60 % 이상"이다.
- 공중 구간(점프)에는 게이트가 없다. 15 m 넘게 떨어진 이웃 게이트 사이가 점프다.

## 4. 핀치 카트 타일 트랙으로 옮기는 예

핀치 카트 트랙은 4 m 타일 격자(직선·커브·출발·잔디)다. RetireX 코스의 **순서와 비율**을 따라 타일을 놓는다.

| RetireX 구간 | 타일 표현 |
| --- | --- |
| 넓은 90° 코너 | `curve` 1개 |
| 헤어핀(180°, 좁음) | `curve` 2개를 붙인 U턴 |
| S자·Z 골목 | `curve` 좌·우를 직선 0~1개 사이에 두고 교대로 |
| 긴 직선(가속 띠) | `straight` 3개 이상 + 띠는 효과음·이펙트로 |
| 지름길 | 핀치 카트 1차 범위 밖(갈림길 타일 없음) — 열린 질문 |
| 점프·고가 | 타일 없음 — 열린 질문 |

예) 캐널 → 8×6 격자 사각 루프 + 한 변에 노치 1개(커브 8개, normal). 풍차 제방의 Z 골목 + 시장 직선 + 헤어핀 둘 → hard(노치 2개)의 노치 자리에 Z를 둔다.
