# RetireX Online 참고 자료 묶음 (핀치 카트용)

2026-10-10 · RetireX Online(마인크래프트 베드락 카트 레이싱 서버) 개발 세션이 정리함.

이 폴더는 **참고용**이다. 핀치 카트가 트랙·미니맵·HUD를 설계할 때 RetireX Online이 실제로 운영 중인 트랙 5종과 그 제작 노하우를 보고 배우라고 둔다. 앱 번들에 들어가는 자료가 아니다.

## 1. 반드시 지킬 것 (라이선스 경계)

RetireX Online은 마인크래프트 위에서 돌아간다. 마인크래프트의 파일 형식·코드·에셋은 Mojang/Microsoft의 것이고 EULA와 사용 지침을 따라야 한다. 핀치 카트는 마인크래프트와 무관한 별도 앱이므로 아래를 지킨다.

| 해도 됨 | 하면 안 됨 |
| --- | --- |
| 이 폴더의 트랙 모양·폭·길이·체크포인트·출발 배치·지름길 구성을 보고 **비슷한 트랙을 핀치 카트의 타일 JSON으로 새로 설계**하기 | 마인크래프트 월드 파일을 가져오기: `db/`(LevelDB), `level.dat`, `.mcworld`, `.mcstructure`, 블록 목록(blocks.json 같은 블록 팔레트 덤프) |
| `tracks/*/track.json`의 좌표를 읽어 중심선을 그리거나 비율을 재기(우리 팀이 만든 코스 데이터다) | RetireX 서버 코드(Go/Dragonfly, LevelDB·NBT·청크·팔레트를 읽고 쓰는 코드)를 옮기거나 흉내 내어 베끼기 |
| RetireX의 지도 규칙(범위 계산, 마커 표시 방식)을 **개념으로** 따라 Swift로 새로 짜기 | 마인크래프트 기본 텍스처·소리·글꼴·모델을 앱에 넣기 — **임시로도 안 됨**(결정 21) |
| 렌더 이미지·카드 그림을 디자인 회의 자료로 보기 | 이 폴더의 렌더 이미지·카드 그림(마인크래프트 텍스처가 찍혀 있음)을 앱 화면·스토어 이미지·홍보물에 쓰기 |

- 트랙 데이터(`track.json`)와 미니맵 그림(`minimap.png`), 미니맵 마커·프레임 그림, `textures/retirex_track_blocks/`의 그림은 RetireX 운영자 쪽이 직접 만든 것이다. 디자이너 본인 프로젝트라 핀치 카트에 써도 된다(결정 20-12). 넣을 때는 PRD 이름 규칙으로 파일명을 바꾼다(결정 20-13).
- 카드 그림(`card.png`)과 렌더(`render_*.png`)에는 마인크래프트 기본 텍스처가 보인다. **참고용으로만** 본다. 레포가 공개라서 이 두 종류는 `.gitignore`로 커밋에서 빼고 디자이너 PC에만 둔다(결정 21).
- `textures/retirex_track_blocks/banner_block_default.png`에는 "MINECRAFT BE RACING GAME SERVER" 문구가 들어 있다. Mojang 상표라 앱에는 이 그림을 그대로 넣지 않는다. 쓰려면 문구를 뺀 핀치 카트용 배너를 새로 만든다.
- 의심되면 그 파일을 앱에 넣지 말고 이 문서 작성 세션(RetireX Online)에 물어본다.

## 2. 텍스처 — 마인크래프트 것은 임시로도 쓰지 않는다

처음 계획은 마인크래프트 텍스처를 임시로 쓰다가 나중에 바꾸는 것이었다. **결정 21(2026-10-10)로 바뀌었다.** RetireX 리소스에 섞여 있는 Mojang 텍스처·소리는 이 앱에 쓰지 않는다. 대신 처음부터 직접 그린 16 × 16 대체 텍스처를 쓴다.

1. 트랙 타일 4종의 `tiles.png`는 처음부터 직접 칠한 색 면이다. 마인크래프트 것이 섞여 있지 않다.
2. 건물·물·나무 같은 풍경 재료는 `Design/textures/tex_<이름>.png`(`node Design/tools/textures.mjs`로 만듦)를 쓴다. 정식 텍스처가 나오면 **같은 파일명**으로 덮어쓴다. 그러면 코드를 바꿀 필요가 없다.
3. RetireX의 렌더·카드 그림에 보이는 마인크래프트 텍스처는 "이런 재료가 이런 색감으로 쓰였다"는 참고로만 본다. 파일은 가져오지 않는다.

RetireX 트랙이 어떤 재료를 어디에 얼마나 썼는지, 그것을 어떤 대체 텍스처로 바꾸는지는 `textures/TEXTURES.md`에 있다.

## 4. 핀치 카트로 옮길 때의 기본 변환

RetireX 트랙은 블록 1칸 = 1 m 좌표이고, 카트 길이가 약 2 m, 주행 폭이 보통 28 m(카트 10대 이상이 나란히 설 만큼)다. 8명이 동시에 달리는 서버라 넓다. 핀치 카트는 혼자 달리는 타임어택이고 노면 3 m, 카트 1.5 m다.

- **크기를 그대로 옮기지 않는다.** 모양(코너의 순서·각도·반경 비율·직선 길이 비율)을 옮긴다.
- 반경·길이는 "카트 길이의 몇 배"로 바꾼다. RetireX 90° 그립 코너(반경 약 10~15 m) ≈ 카트 길이의 5~7배 → 핀치 카트에서는 4 m 타일의 1/4 원호(반경 2 m ≈ 카트 1.3배)가 가장 가까운 단위다. 좁은 헤어핀처럼 감속이 필요한 코너는 타일 2개를 쓰는 U턴으로 표현한다.
- 한 바퀴 길이는 RetireX가 900~3,450 m(랩 1~2분)라 그대로 줄이면 너무 길다. 핀치 카트의 60~140 m 규칙(테크 PRD 7장)에 맞춰 **구간을 골라** 쓴다. 예: 캐널(가장 쉬움)의 외곽 사각 루프 + S자 하나, 풍차 제방의 Z 골목 + 헤어핀 둘.
- 체크포인트는 RetireX의 KEY 게이트(트랙당 2~19개)를 핀치 카트 체크포인트 3개로 줄인다. 한 바퀴를 대략 3등분하는 위치의 KEY를 고른다.
- 높이(고가·점프·경사)는 핀치 카트 타일 4종에 없다. 쓰려면 타일 종류를 늘려야 하므로 열린 질문으로 남긴다.
