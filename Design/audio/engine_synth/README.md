# 엔진음 합성 대체본

`node Design/tools/engine.mjs --synth`로 만든다. 단기통 엔진의 점화 펄스, 낮은 잡음, 두 단 저역 통과를 코드로 합성했고, 외부 소재가 없어 팀 소유다.

`Assets/sfx/`의 엔진음(XK ENGINE 원본)을 공개 레포에 올릴 수 없다고 확인되면 이 5개를 `Assets/sfx/`로 복사한다. 파일명과 루프 여부가 같고 단발 소리 길이도 0.01초 안쪽으로 같아서, `Assets/sfx/ENGINE.md`의 규칙과 코드를 그대로 쓴다. 출처와 라이선스는 `Assets/sfx/LICENSES.md` 3장에 있다.
