`preview.png`에서 시각 후보를 비교할 수 있다. 애니메이션 시트는 첫 프레임만 보여 준다. 실제 게임 재생 검증 결과가 아니다. 추가 효과음 3종은 Assets/sfx/ui-cues/에 원본 OGG와 M4A를 준비했다. 원본 음량·속도·채널 수를 유지했다. lap-preview.png는 일반 랩 98개와 FINAL LAP를 모두 보여 준다.

## 제외·보류

- `entity/gate_marker.json`은 `geometry.pig`와 `textures/entity/pig/pig`를 참조하므로 모장 바닐라 자산으로 제외했다. 모델·텍스처를 복사하지 않았다.
- 모장 몹 기반 아이템/이펙트, 스킨·기본 글꼴, 바닐라 텍스처·소리는 후보로 가져오지 않는다.
- RetireX 전용 로고·브랜드 문구·장식은 핀치 로버에 그대로 맞지 않아 제외했다.
- 기존 5종 카트 외 로스터 확대와 아이템 레이스 리소스는 이번 준비 범위에서 보류했다.
- discovery4 모델링 파일은 읽거나 복사하지 않았다.

사용자가 지정한 로컬 RP의 manifest 버전은 `[2,1,12]`다. 이것을 실제 운영 서버 버전으로 해석하지 않는다. RP에 있는 것만으로 각 파일의 제3자 출처·공개 사용 조건이 증명되지는 않으므로, 신규 소리에 기존 엔진음의 CC0 기록을 적용하지 않는다. 사용자 승인 기록과 원본 해시를 별도로 보관한다.

## 재준비

```powershell
node Design/resource-audit/prepare.mjs
```
