## 시작하기

1. 저장소를 클론합니다.
2. `KartSimulator.xcodeproj` (또는 `.xcworkspace`)를 Xcode에서 엽니다.
3. 시뮬레이터 또는 실기기를 선택해 빌드 및 실행합니다.

## 브랜치 / 협업 규칙

- 작업은 기능 단위로 브랜치를 분리해 진행합니다. (예: `feature/track-selection`)
- 변경 사항은 Pull Request를 통해 공유 및 리뷰합니다.
- 커밋 메시지는 변경 목적을 간단히 설명합니다.
