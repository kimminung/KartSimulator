## 디자인 피드백

PR·날짜별로 아래 접은 항목을 하나씩 추가해 캡처와 피드백 요청 사항을 남깁니다. 디자이너는 각 항목을 펼쳐 이미지와 요청 사항을 확인해 주세요.

<details>
<summary>2026-10-10 — 카트 선택 메뉴 1차 구현 화면 (디자이너 확인 요청)</summary>

Vision Pro에서 캡처한 현재 메뉴 화면입니다. 아직 `Docs/design-prd.md`의 팔레트·픽셀 폰트·아이콘 스타일 가이드는 반영되지 않은 기본 SwiftUI 스타일입니다. 아래 항목에 대해 디자이너 피드백을 부탁드립니다.

- **카트 아이콘**: 6종(`Arcrix`, `Bogub Kart`, `Gospel`, `Razr`, `Sirius`, `MMS`) 모두 동일한 SF Symbols 차 아이콘(임시)을 쓰고 있습니다. 실제 카트별 썸네일/실루엣으로 교체가 필요한데, 디자인 PRD 3장 아이콘 규격(24×24, 2px 선)에 맞춰 작업 가능한지 확인 부탁드립니다.
- **색상 스와치**: 17개 색상 원이 라벨 없이 촘촘하게 붙어 있습니다. 크기·간격을 키울지, 선택 시 색상 이름을 보여줄지 의견 부탁드립니다.
- **타이틀/본문 타이포**: "핀치 카트" 제목과 본문이 시스템 폰트로 표시됩니다. 디자인 PRD의 픽셀 폰트(Galmuri)를 제목에만 적용하는 방향이 맞는지 확인 부탁드립니다.
- **카드/버튼 스타일**: 카트 카드와 "박스 열기" 버튼이 기본 `.regularMaterial`/기본 버튼 스타일입니다. 모서리 반경, 글래스 재질, 선택 상태 표시(현재는 파란 테두리만) 방향에 대한 의견 부탁드립니다.

<summary>2026-10-10 — 디자인 피드백 반영 결과 (`Docs/decisions.md` 20·21번)</summary>

위 요청에 대한 디자이너 답변(결정 20·21번)을 받아 테크 쪽에서 반영한 내용입니다.

- **카트 아이콘** → SF Symbols 임시 아이콘 대신, 메뉴 카드에 실제 USDZ를 `Model3D`로 띄우고 드래그로 360도 돌려볼 수 있게 했습니다(아래 "메뉴 카트 360° 회전" 항목과 동일 작업). HUD·미니맵용 픽셀 실루엣은 디자인 자료 전달 대기 중입니다.
- **색상 스와치** → 원 크기 28→40pt, 간격 10→14pt로 키우고, 정렬을 알파벳 순에서 색상환 순(빨강→...→핑크, 갈색·무채색은 끝)으로 바꿨습니다.
- **타이틀/본문 타이포** → 제목에만 픽셀 폰트(Galmuri)를 쓰는 방향은 확정됐지만, 폰트 파일이 아직 저장소에 없어 적용은 보류 중입니다. 파일 전달해 주시면 바로 적용하겠습니다.
- **카드/버튼 스타일** → 글래스 재질(`.regularMaterial`) 그대로 유지하기로 했습니다(이후 UI 작업 중 바뀔 수 있음).
- **카트 로스터** → `arcrix`/`bogubkart`/`gospel`/`razr`/`sirius` 5종으로 확정하고, `mms`는 카트가 아니라 일반 자동차 모델이라 제외했습니다 — 리소스 파일(29MB)도 같이 지웠습니다.
- **메뉴 카트 360° 회전** → 드래그로 카트를 돌려 볼 수 있게 추가했습니다.
- **박스 다이오라마 치수** → 실기기 테스트를 거친 현재 값(0.7 × 0.4 × 0.7m)으로 확정합니다. PRD 원안(1.4×0.6×1.1m)보다 작은데, 책상 위 디오라마 느낌과 손 리치를 실기기로 직접 확인하며 맞춘 값입니다.
- **엔진음 루프 / RetireX 색 팔레트(`Design/style-guide.md`) / 바닐라 텍스처 교체** → 소리·팔레트 자료, 타일 텍스처 전달을 기다리고 있습니다. 전달되면 바로 연결하겠습니다.

1. 저장소를 클론합니다.
