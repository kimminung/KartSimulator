## 디자인 피드백

### 2026-10-10 — 카트 선택 메뉴 1차 구현 화면 (디자이너 확인 요청)

Vision Pro에서 캡처한 현재 메뉴 화면입니다. 카트 6종(`Arcrix`, `Bogub Kart`, `Gospel`, `Razr`, `Sirius`, `MMS`) 선택 그리드와 색상 스와치, "박스 열기" 버튼이 보입니다. 아직 `Docs/design-prd.md`의 팔레트·픽셀 폰트·아이콘 스타일 가이드는 반영되지 않은 기본 SwiftUI 스타일(차 아이콘은 SF Symbols 임시 아이콘)입니다. 디자이너는 이 화면을 기준으로 레이아웃·색상·아이콘 방향에 대한 피드백을 부탁드립니다.

## 시작하기

1. 저장소를 클론합니다.
2. `KartSimulator.xcodeproj` (또는 `.xcworkspace`)를 Xcode에서 엽니다.
3. 시뮬레이터 또는 실기기를 선택해 빌드 및 실행합니다.
