## 시작하기

1. 저장소를 클론합니다.
2. `KartSimulator.xcodeproj` (또는 `.xcworkspace`)를 Xcode에서 엽니다.
3. 시뮬레이터 또는 실기기를 선택해 빌드 및 실행합니다.

## 사용법

1. 메뉴 창에서 카트와 색상을 고른 뒤 **박스 열기** 버튼을 누르면 눈앞에 트랙 박스가 열립니다. 앉아서 플레이하면 편합니다.
2. 첫 실행 때는 조작법 화면이 자동으로 뜹니다. 위쪽 "디오라마 / 1인칭 / 3인칭" 탭으로 모드별 조작법을 볼 수 있고, 나중에는 메뉴 창의 **조작법** 버튼으로 다시 열 수 있습니다. 이 탭은 설명만 바꿔 보여 줄 뿐, 실제 운전 모드는 바꾸지 않습니다.
3. 박스 위에 떠 있는 HUD 패널에서 운전 모드를 고르고 주행합니다. HUD의 양손 점(핀치 중이면 청록색)·화살표·페달 게이지로 손 입력이 어떻게 인식되는지 볼 수 있습니다.
4. 주행을 마치면 HUD(또는 메뉴 창)의 **박스 닫기** 버튼으로 닫습니다.

### 운전 모드 3종

1인칭 주행은 어지러움을 일으킬 수 있어서, 몰입도가 다른 세 가지 모드를 둡니다(`Docs/decisions.md` 39번).

| | 디오라마 (기본) | 1인칭 | 3인칭 |
| --- | --- | --- | --- |
| **시점** | 박스를 밖에서 내려다봄 | 카트에 탄 시점 (Phase 2) | 1인칭과 같은 시점 |
| **조향** | 한 손만 핀치 → 좌/우회전 | 머리 방향을 따라 서서히 | 한 손만 핀치 → 좌/우회전 |
| **전진·가속** | 양손 핀치 유지 | 한쪽 손이라도 핀치 | 양손 핀치 |
| **후진** | 핀치한 채로 양손 벌리기 | 없음 | 없음 |

세 모드 모두 양손을 다 떼면 서서히 멈춥니다.

> **지금은 Phase 1입니다.** 세 모드 모두 아직 같은 크기의 박스로 보이고 **조작 방식만** 다릅니다. 1인칭·3인칭에서 트랙을 실제 크기로 키우고 카트를 내 머리 위치에 맞춰 카트에 탄 듯 보이게 하는 작업은 다음 단계(Phase 2)에서 진행합니다.

### 모드 전환

HUD 패널 맨 위의 **디오라마 / 1인칭 / 3인칭** 버튼 중 원하는 버튼을 **바라보면서 핀치**하면 바로 바뀝니다. 지금 모드는 색이 채워진 버튼으로 표시됩니다.

- **"아이트래킹"은 정확히는 시선+핀치 버튼 선택입니다.** visionOS는 서드파티 앱에 실제 눈동자 방향을 주지 않기 때문에, 다른 visionOS 버튼을 누를 때와 같은 시스템 표준 방식(바라보고 → 핀치)으로 고릅니다.
- 버튼을 보면서 핀치하면 모드 전환, 박스를 보면서 핀치하면 운전 입력으로 들어갑니다.
- 박스를 새로 열면 항상 디오라마 모드로 시작합니다.

### 디오라마 모드 (기본)

박스를 밖에서 보면서 카트를 직접 조종합니다.

| 동작 | 조작 |
| --- | --- |
| 전진 | 양손을 핀치한 채로 있으면 전진 (최고 속도까지 가속) |
| 후진 | 핀치한 채로 양손을 벌리면 후진, 더 벌릴수록 빨라짐 (최고 속도는 전진의 절반) |
| 좌회전 | 오른손을 떼면(왼손만 핀치) 좌회전 |
| 우회전 | 왼손을 떼면(오른손만 핀치) 우회전 |
| 정지 | 양손을 떼면 서서히 멈춤 |

- **기준점은 핀치를 시작한 순간의 손 간격입니다(절대 거리 아님).** 손을 가깝게 모으고 시작하든 넓게 벌리고 시작하든 그 자리에서 바로 전진하고, 거기서 더 좁혀도 계속 전진합니다. 기준보다 4 cm 넘게 벌리면 후진이 시작되고, 거기서 25 cm를 더 벌리면 최대 후진입니다(`InputTuning` 기본값). 예전 조작법 안내의 "양손 사이 약 40 cm = 중립"은 더 이상 맞지 않습니다.
- 한 손이라도 떼면 기준점이 지워지고, 다시 양손을 핀치하는 순간 새로 잡힙니다. 회전하느라 한 손을 뗐다가 다시 잡을 때도 마찬가지입니다.
- 회전하는 동안에는 속도가 유지됩니다. 달리다 한 손을 떼면 그 속도로 돌고, 멈춰 있을 때는 제자리에서 돕니다.
- 좌/우는 카트 기준입니다. 카트가 나를 향해 달려올 때는 내 쪽에서 볼 때 좌우가 반대로 보입니다.

### 1인칭 모드

머리가 향하는 방향으로 카트가 서서히 방향을 틀고, 손은 가속·감속만 맡습니다.

| 동작 | 조작 |
| --- | --- |
| 조향 | 고개를 돌리면 그 방향으로 카트가 서서히 회전 (기본 초당 최대 120°) |
| 가속 | 한쪽 손이라도 핀치하고 있으면 가속 |
| 감속·정지 | 양손을 모두 떼면 감속하다 멈춤 |

- 조향은 눈동자가 아니라 **머리(기기) 방향**을 따릅니다. 박스를 정면으로 보고 있으면 카트도 내가 보는 방향(앞)으로 달리고, 고개를 왼쪽으로 돌리면 카트도 왼쪽으로 돕니다.
- 손 간격이나 왼손/오른손 구분은 쓰지 않습니다. 후진은 없습니다.

### 3인칭 모드

1인칭과 같은 시점이지만, 조향은 이 프로젝트가 처음 썼던 한 손 핀치 좌/우회전 방식입니다.

| 동작 | 조작 |
| --- | --- |
| 전진 | 양손을 핀치하면 전진 (손 간격과 상관없이 항상 최고 속도까지 가속) |
| 좌회전 | 왼손만 핀치하면 좌회전 |
| 우회전 | 오른손만 핀치하면 우회전 |
| 정지 | 양손을 떼면 서서히 멈춤 |

- 후진은 없습니다. 디오라마와 달리 양손을 벌려도 계속 전진합니다.
- 회전 중 속도 유지, 좌/우가 카트 기준인 점은 디오라마와 같습니다.
